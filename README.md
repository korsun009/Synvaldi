# Synvaldi

Synvaldi synchronizes parts of a Windows Vivaldi workspace through a self-hosted ASP.NET Core and PostgreSQL service. The desktop client lives in the Windows notification area. See the [Russian design and acceptance plan](docs/PLAN.ru.md) and [server deployment guide](server/README.ru.md).

## Текущий режим работы

* Обычные HTTP(S)-вкладки можно зеркалировать между работающими Vivaldi при явном выборе всех вкладок. Требуется дополнение Synvaldi.
* Выбранные пространства со стопками, порядком и закрепами синхронизируются через сохранённую сессию **закрытого Vivaldi**. Открытый браузер держит текущий файл сессии заблокированным. Эти два режима имеют разные границы применения. По умолчанию на новом устройстве не закреплено ни одного пространства.
* Профиль Synvaldi привязывается к локальному профилю Vivaldi в мастере. Сервер обрабатывает пароль аккаунта, отдельные устройства и историю версий за 72 часа. Отозванный клиент должен пройти допуск заново.
* Переносимые настройки дополняют штатный Sync. Учитывается реестр syncable установленной версии. Поддерживаются ссылки на локальные фоны PNG/JPEG/WebP и вложения заметок. Вложения применяются после появления родительской заметки в целевом профиле. Профиль закрывают перед записью настроек.

## Установка клиента

1. Запусти EXE выпуска под обычной учётной записью Windows. Для собственного TLS-сертификата выбери файл подключения, полученный от администратора сервера. Его отпечаток проверяется только приложением.
2. В мастере введи адрес, создай аккаунт Synvaldi или войди в существующий. Выбери локальный и облачный профили. На первом ПК укажи исходные пространства. На остальных выбери, какие местные пространства импортировать.
3. Для живого обмена обычными вкладками открой управление расширениями Vivaldi, разреши загрузку распакованного расширения и укажи папку `extension` рядом с установленным `Synvaldi.exe`. При выборе режима всех вкладок будут обрабатываться HTTP(S)-вкладки управляемого профиля. Убедись, что выбран нужный профиль. Установщик зарегистрирует отдельный Native Messaging host для расширения.
4. Для выборочных пространств используй раздел «Пространства». Выход из окна настроек возвращает клиент в трей. В автозагрузке Windows можно отключить запуск агента при входе.
5. Для удаления используй «Установленные приложения → Synvaldi → Удалить». Профили Vivaldi и облачные данные хранятся отдельно.

## Сборка и тесты

Для разработки нужны .NET SDK 10 с Windows desktop targeting packs, Node.js для тестов расширения, PostgreSQL 17 и Inno Setup 6. Установщик включает .NET runtime x64. На Linux сервер собирается отдельным Docker Compose проектом.

```powershell
dotnet build desktop/Synvaldi.csproj -c Release
dotnet run --project integrations/Tests/Tests.csproj
node --test browser/tests/model.test.mjs
./installer/build.ps1
```

Сценарий выпуска подписывает JSON-манифест обновления с размером и SHA-256 установщика. Клиент доверяет встроенному открытому ключу, загружает установщик с GitHub Releases и перед запуском проверяет подпись и содержимое. Сам EXE требует отдельного сертификата Authenticode при распространении с подписью Windows. Раздел обновлений ориентирован на стабильные релизы. Ключ публикации не входит в репозиторий.
